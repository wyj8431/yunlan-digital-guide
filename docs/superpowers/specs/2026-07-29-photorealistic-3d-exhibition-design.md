# 写实 3D 展馆升级设计

## 目标

把现有低多边形白盒展馆升级为桌面端写实数字展馆。空间以江南园林为骨架，以当代博物馆展柜为展陈语言，使用本地 GLB、PBR 纹理和 HDR 环境光替换核心展品的基础几何占位，同时保留现有漫游、碰撞、展品详情、西湖切场和视频中心入口。

## 视觉方向

室内采用深木格栅、月洞门、灰色石材铺装和借景构成江南空间层次，不制作仿古街景。展柜使用低铁玻璃、拉丝黑钛金属框、石材基座、暖白灯带和独立中文标签牌，保持正式博物馆质感。

入口视线穿过月洞门指向后墙西湖长卷。中央保留至少 2.4 米主通道，两侧布置四组核心展品：西湖绿道自行车、绿色接驳车、龙井茶具和丝绸服饰。自行车和车辆使用开放式低台；茶具和丝绸使用封闭玻璃柜。角落绿植只承担借景和遮挡过渡，不再使用球形树冠。

西湖场景同步升级为写实环境，包含真实水面、自然岸线、石质拱桥、树木模型、雷峰塔、远山雾和天空环境。程序化几何只用于地形、不可见碰撞体和资源加载失败后的精细降级模型。

## 材质与灯光

所有主要建筑表面使用 PBR 材质：

- 石材地面包含基础色、法线、粗糙度和环境遮蔽贴图，并按真实铺装尺度显示拼缝和轻微色差。
- 胡桃木格栅的纹理方向跟随构件长轴，避免大面积重复图案。
- 展柜玻璃具有真实厚度、低色偏透明度、边缘高光和受控环境反射。
- 金属框使用拉丝黑钛质感，石材基座与地面有可辨别的粗糙度差异。
- 西湖水面使用法线扰动、菲涅耳反射、透明度和缓慢波动，不使用纯色平面。

灯光由 HDR 环境反射、环境补光、吊顶隐藏灯槽、轨道聚光灯和展柜灯带组成。重点灯对准展品，墙面与通道保持柔和层次；曝光和色调映射必须避免现有顶部灯具的白色过曝。

## 写实资产

四组核心展品必须使用高质量本地 GLB：自行车、绿色接驳车、龙井茶具和丝绸服饰。资产必须满足以下条件：

- 允许项目演示和再分发，仓库记录来源、作者、许可证和署名要求。
- 模型使用合理真实尺寸，原点、朝向和阴影设置统一。
- 优先 Draco 压缩网格；纹理以 1K 或 2K 为主，避免无收益的 4K 贴图。
- 材质命名稳定，便于运行时校正色彩空间、粗糙度和透明度。
- 每个资产都有显式包围盒、点击根节点和地面碰撞范围。

建筑、展柜、月洞门、西湖长卷、场景地形和不可见碰撞体继续由 Three.js 构建，以保证尺寸、动线、交互和性能可控。

## 资源架构

新增统一资产清单，记录本地路径、类型、许可信息、尺寸、缩放、朝向、点击 ID、碰撞范围和降级工厂。资源加载层负责 GLTFLoader、DRACOLoader、HDR 环境图、PBR 纹理、缓存、进度、错误和释放。

场景拆分为五个职责清晰的模块：

1. 园林建筑：墙体、吊顶、月洞门、木格栅、地面、墙脚线、消防出口和地面导视。
2. 灯光环境：HDR、色调映射、环境补光、灯槽、轨道灯、展柜灯带和阴影预算。
3. 专业展柜：开放低台、封闭玻璃柜、标签牌和内部照明。
4. 写实展品：四组 GLB 的加载、摆放、点击、碰撞和降级。
5. 西湖户外：水面、岸线、桥、植被、雷峰塔、远山、雾和户外碰撞。

React 只管理 `loading | hall | detail-open | transitioning | lake | render-error` 页面状态和进度 UI。Three.js 模块管理场景图、输入、碰撞、动画、材质与 GPU 资源。现有展品 ID 和 `/videos` 路由契约保持不变。

## 交互与碰撞

保留鼠标指针锁、WASD、方向键、Escape、展品悬停和点击详情。详情打开时暂停相机输入，关闭后恢复。室内墙体、月洞门侧墙、展柜、开放展台、自行车、车辆和主要装饰均参与碰撞；中央主通道保持至少 2.4 米。

西湖岸线和水域不可进入，苏堤与桥面可行走，桥栏、塔基和主要树木参与碰撞。移动继续使用帧间隔上限、对角归一化和轴向滑动。

## 加载、降级与资源释放

进入展馆时显示真实资源进度，不显示伪造百分比。单个 GLB 加载失败时使用对应精细降级模型并记录错误，不阻断其他展品；HDR 或 PBR 贴图失败时退回受控纯色材质。WebGL 初始化失败时显示错误提示，返回首页和数字人客服入口仍可操作。

离开展馆、切换西湖或组件卸载时，必须取消动画帧，移除输入、媒体查询和 ResizeObserver 监听，释放几何体、材质、纹理、PMREM 目标、渲染器上下文和画布。共享资源按引用或所有权只释放一次。

## 性能预算

- 桌面目标视口为 1440×900 和 1920×1080。
- 室内平均帧率不低于 45 FPS，西湖平均帧率不低于 40 FPS。
- 像素比上限为 2；低性能模式上限为 1.25。
- 纹理优先 1K/2K，重复建筑与植被复用几何体、材质或实例。
- 阴影只分配给主要灯光和重点展品，远景和次要装饰不投射动态阴影。
- 远景树木、山体和次要模型使用距离分级或简化几何。

## 验收标准

1. 1440×900 与 1920×1080 的真实浏览器截图中，展馆不再呈现白盒房间、纯色方块展品、球形树或圆锥山。
2. 月洞门、木格栅、石材地面、专业展柜、水纹长卷和四组写实展品在首个视线动线中形成清晰层次。
3. 自行车、接驳车、龙井茶具和丝绸服饰均由本地 GLB 成功加载、正确缩放、投射合理阴影并可点击。
4. 核心材质具有可见但克制的法线、粗糙度、反射和贴图尺度，灯光无明显过曝。
5. 室内主要物体、西湖水域、桥栏和塔基碰撞正确，主通道宽度符合要求。
6. 重复进入展馆和西湖五次后只存在一个活动画布，控制台无新增资源或 WebGL 错误。
7. 室内与西湖平均帧率达到性能预算；不达标时自动降低像素比、阴影或远景细节。
8. 单资产、HDR、纹理和 WebGL 失败路径均有可操作降级，页面不会黑屏或失去返回入口。

## 不在范围内

- 不制作照片级数字孪生或激光扫描建筑。
- 不加入多人漫游、编辑器、移动端虚拟摇杆或 VR 模式。
- 不在运行时从第三方网站加载模型、纹理或 HDR。
- 不重写视频中心、数字人客服或路由系统。
