# 3D 展馆综合功能完善设计

## 目标

在现有 React、Three.js 展馆基础上完成可稳定演示的西湖主题 3D 展馆。保留当前“青瓷绿、石灰白、深木色”的当代展馆方向，不推翻现有路由、展品详情和视频中心联动。

## 交付范围

### 室内展馆

- 使用现有 `Scene`、`PerspectiveCamera`、`WebGLRenderer` 和灯光系统构建完整封闭房间。
- 墙面、地面、顶面和展陈装置使用统一材质体系，材质差异仅用于表达石材、木材、金属、水面和植物。
- 保留并完善壁画、吊灯、展桌、自行车、景区接驳车、绿植和西湖数字沙盘。
- 每个主要展品具有稳定的展品 ID，可通过射线点击打开图文介绍。
- 展品详情继续提供“进入西湖沙盘”或“前往视频中心”等明确操作。

### 漫游与相机

- 桌面端使用鼠标控制第一人称视角，使用 `W/A/S/D` 和方向键移动。
- 相机保持固定视点高度，俯仰角受限，避免镜头翻转。
- 房间边界始终限制相机中心，玩家半径与墙面保持安全间距。
- 碰撞采用按轴移动，正面受阻时仍允许沿未阻挡方向滑动。
- 页面失焦、弹出展品详情或切换场景时清理按键状态，避免持续移动。

### 碰撞系统

- 房间、展台、展桌、自行车、接驳车、沙盘和主要落地绿植均注册 AABB 碰撞体。
- 装饰性壁画和吊灯不阻挡地面移动。
- 碰撞体尺寸与可见模型保持一致，允许少量安全边距，但不能形成明显空气墙。
- 碰撞计算保持为独立纯函数，Three.js 渲染层只负责注册碰撞体和应用移动结果。

### 西湖场景

- 从室内西湖数字沙盘进入独立轻量场景，并可固定返回展馆。
- 场景包含湖面、岸线、苏堤、桥、树木、雷峰塔和远山层次。
- 保留低多边形表达，优先保证画面完整、漫游清晰和性能稳定。
- 西湖场景具有独立移动边界和景观碰撞，不能走入湖面、穿过桥体或离开场景范围。

### 交互反馈

- 鼠标经过可交互展品时显示高亮和指针反馈。
- 点击命中只选择最近的有效展品，误点地面或墙面不会打开弹窗。
- 展品详情打开时暂停相机视角捕获；关闭后恢复漫游。
- 控制提示保持紧凑，不遮挡展品详情、返回按钮和数字人客服入口。

## 代码边界

- `ExhibitionRenderer.ts`：室内场景装配、相机、输入、射线和生命周期。
- `collision.ts`：房间约束、圆形玩家与 AABB 碰撞、按轴滑动纯函数。
- `westLakeScene.ts`：西湖场景装配、漫游、边界与资源释放。
- `ExhibitionPage.tsx`：React 场景切换、展品详情和页面操作。
- 必要时拆出 `exhibitionAssets.ts` 或 `exhibitionMaterials.ts`，仅用于减少真实重复，不引入通用场景框架。

## 异常与降级

- WebGL 初始化失败时显示可访问的错误提示，首页导航仍可使用。
- 切换场景必须释放动画帧、监听器、几何体、材质、纹理和 WebGL 上下文。
- `ResizeObserver` 不可用或容器尺寸为零时采用安全尺寸，不产生空白画布或异常纵横比。
- 低性能设备降低像素比与阴影质量，不删除核心展品和碰撞。

## 验收标准

- 室内场景非空，材质与灯光一致，主要展品全部可见。
- 鼠标视角、WASD 和方向键均可工作，相机不能离开房间。
- 所有主要落地物体均不能被穿透，受阻时允许合理滑动。
- 每个可交互展品可打开正确详情，沙盘可进入西湖场景并返回。
- 西湖场景包含规定景观，边界和主要景物碰撞有效。
- 桌面视口中控制提示、返回按钮、客服入口和详情面板不重叠。
- 单元测试覆盖碰撞、输入、射线、生命周期和 React 场景切换。
- Playwright 验证桌面画布非空、像素非单色、布局无重叠、场景切换成功。

## 非目标

- 不制作测绘级西湖地形或影视级写实模型。
- 不引入移动端虚拟摇杆、多人同步、账号系统或展馆编辑后台。
- 不下载来源不明的商业 3D 模型；本阶段使用程序化低多边形模型和项目现有资源。
