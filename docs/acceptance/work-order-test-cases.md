# Work-Order Acceptance Test Cases

This checklist separates executable local tests from environment-dependent acceptance. Mark a case only with
a command log, screenshot, or external platform export captured for the current diff.

| Domain        | Case                                                                         | Expected result                                                                                                                                                    | Evidence type                                        |
| ------------- | ---------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------- |
| Ticket        | Member creates a ticket for an accessible project                            | Ticket is visible to that project and assignee notification is recorded.                                                                                           | API/E2E                                              |
| Ticket        | Retry status or assignee change with the same idempotency key                | One event and one version increment are persisted.                                                                                                                 | Java concurrency test                                |
| Ticket        | Retry create with the same `Idempotency-Key` and body                        | Original ticket is replayed; a changed body returns `409 IDEMPOTENCY_KEY_REUSED`; missing/blank/overlong keys return `400 IDEMPOTENCY_KEY_REQUIRED`.               | `TicketApiTest` + `TicketIdempotencyConcurrencyTest` |
| Ticket        | Non-reporter, non-admin reassigns a ticket                                   | Stable `FORBIDDEN` response.                                                                                                                                       | API test                                             |
| Learning      | Correct answer submission                                                    | Attempt is recorded and model provider is never called.                                                                                                            | `LearningServiceTest`                                |
| Learning      | Unknown question                                                             | Stable `QUESTION_NOT_FOUND` response.                                                                                                                              | API test                                             |
| Learning      | Learner calls staff review endpoint                                          | Stable `FORBIDDEN` response.                                                                                                                                       | `LearningServiceTest` + `LearningLocalApiTest`       |
| Learning      | Model response times out or is malformed                                     | Incorrect attempt remains stored; no unvalidated diagnosis is published.                                                                                           | Provider/service test                                |
| Learning      | Teacher rejects a diagnosis                                                  | Learner receives `REJECTED` status but cannot read the rejected candidate; UI explains that a retry creates a new candidate.                                       | `LearningServiceTest` + work-order UI                |
| Learning      | Prompt injection string in reasoning                                         | Reasoning remains structured data and validation gates output.                                                                                                     | Provider regression test                             |
| Learning      | Submit-attempt load                                                          | `learning-submit` measures concurrent deterministic grading and diagnosis degradation under the configured local account.                                          | `tools/work-orders-load-test.mjs`                    |
| Alert         | Queue is full                                                                | Stable `ALERT_QUEUE_FULL` 503 response.                                                                                                                            | Queue plus MockMvc test                              |
| Alert         | Cross-bucket alerts                                                          | Events persist into their corresponding five-minute UTC groups.                                                                                                    | Writer test                                          |
| Alert         | Accepted events during shutdown                                              | Intake closes, accepted work drains within timeout, timeout logs remaining counts.                                                                                 | Queue test/Compose stop drill                        |
| Alert         | Historical Koa fixture compatibility                                         | Run only after historical route, auth, payload, and fixture are supplied.                                                                                          | External blocker                                     |
| Coze          | Stop and resend a generated answer                                           | UI aborts the active request and submits a new request without duplicate messages.                                                                                 | Browser test                                         |
| Coze          | Guide stream protocol lifecycle                                              | A newer request cancels the older one; disconnects cancel active work; malformed messages return a stable error; oversized frames close before attachment parsing. | `guide-websocket.test.ts`                            |
| Coze          | Guide request size boundary                                                  | HTTP bodies larger than the JSON limit return stable `413 PAYLOAD_TOO_LARGE`; WebSocket frames are capped for the 10 MiB attachment policy.                        | `api.test.ts` + `guide-websocket.test.ts`            |
| Web build     | Tailwind utility layer is available without resetting existing global styles | Vite build succeeds and the generation controls use Tailwind utilities alongside legacy CSS.                                                                       | `npm --workspace apps/web run build`                 |
| Coze          | Platform evaluation                                                          | At least 90% platform score and raw results retained.                                                                                                              | External platform                                    |
| Lip sync      | Microphone realtime input                                                    | User grants permission, RMS changes with speech, tracks stop on reset/unmount.                                                                                     | Browser test                                         |
| Lip sync      | Live2D mouth movement                                                        | Authorized production Cubism model receives mouth parameters during speech.                                                                                        | License + browser test                               |
| Review skills | Three review commands                                                        | Cursor desktop executions produce the documented finding contract.                                                                                                 | Cursor screenshot/log                                |
| Review skills | Performance/stability                                                        | Record median and P95 review latency plus repeated command pass rate.                                                                                              | Local report                                         |
