# XFYUN Avatar Web SDK

The application expects the official SDK entry at:

`avatar-sdk-web_3.2.3.1002/esm/index.js`

Download `avatar-sdk-web_3.2.3.1002.zip` from the official XFYUN Web SDK documentation and extract the complete directory here. Keep `index.js`, `index.d.ts`, and all player chunks in the same directory because the SDK loads those chunks dynamically.

Official documentation:

https://www.yuque.com/xnrpt/bbc1du/ht4a2a2vstvb13se
